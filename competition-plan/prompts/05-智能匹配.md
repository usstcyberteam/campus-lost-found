# 阶段 5｜物品理解、匹配与证据卡

输入：已确认业务接口、官方模型接口说明和后端本地配置。密钥不要粘贴到对话。

```text
本次实现物品特征提取与匹配。先核对官方接口、账号可用性和模型标识，不猜测调用格式。

处理流程：图片/文字 → 提取特征 → 用户确认 → 检索排序 → 证据卡 → 人工核验。

提取类别、颜色、品牌、形状及独特标记；无法判断留空。用户确认后才能用于发布与匹配。

初始权重：语义60%、特征25%、时间10%、地点5%。缺失项重新归一化。仅对用户确认的明显类别冲突进行排除，地点不作硬过滤。

最多返回三个候选，解释一致项、冲突项、时间地点关系和缺失信息。排序分数不表示找回概率。阈值设为可配置，后续只用验证集确定。

模型密钥仅存后端；限制图片大小、调用量和超时，缓存重复请求。发送图片与描述前获得用户明确确认。不要将私密认领证据、联系方式或路线发送给模型。

未配置、超时或失败时保留手动流程，规则、缓存和模型结果分别标识。不得伪造模型输出。

添加成功、无图片、解析失败、无候选、同款物品和模型故障检查，记录实际调用及未验证项。不要进入下一阶段。
```

验收：特征经确认，候选有解释；来源明确，模型失败时业务仍可完成。
