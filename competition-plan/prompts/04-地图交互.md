# 阶段 4｜地图与游戏委托式交互

输入：已通过验收的业务接口、有权使用的底图或自绘示意图。

```text
基于已完成的业务接口实现地图，不改动无关后端逻辑。

使用 Leaflet 图片图层，包含一个室外示意图和一栋楼两个楼层。使用自绘或获准使用的底图，明确地图版本和归一化坐标。

完成：
1. 图层切换、缩放、标点和选点。
2. 室外圆形范围绘制及清除。
3. 手绘路线、撤销和分层片段保存。
4. 大厅卡片定位地图，地图标记打开对应详情。
5. 保存、刷新和切换图层后数据一致。
6. 手机尺寸下可用的触控和表单。

路线默认仅本人可见，不能进入公共记录接口；跨楼层片段分别存储，不强行连线。
未标定比例尺时不输出米数，不制作3D或自动导航。

学生端采用清晰的委托卡和轻量卡通图标；工作人员端以工单效率为主。补齐加载、空记录、错误和成功状态。

验证坐标、范围、路线保存及图层切换；报告实际检查和剩余问题。不要进入下一阶段。
```

验收：地图和大厅来自同一记录，保存后可恢复；不是静态展示，不能暴露他人路线。
