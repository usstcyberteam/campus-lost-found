# AI 全局悬浮助手 - 交接文档

> 分支：`feature/ai-assistant-global-v1` · 日期：2026-10-22 · 功能负责人：AI 模块负责人（A1/A2/A3）

## 1. 功能概述

全局可拖动的 AI 悬浮助手：登录后在任意页面左侧/右侧出现竖条状停靠条，可拖动、松手自动吸附到较近一侧边缘并带过渡动画；点击展开聊天框，与后端 `/api/v1/ai/chat` 对话，模型自动识别失物/拾获意图并提取结构化字段（标题、分类、地点、楼层、时间等），确认后跳转发布页并通过 URL query 预填表单（只填空字段，绝不覆盖用户手写）；另提供历史地点推荐接口 `/api/v1/ai/suggest-locations`；模型不可用时自动降级为规则模式，不报错、不阻断手动发布。

## 2. 架构设计

- **前端**：`frontend/src/components/AiFloat/AiFloatWidget.tsx`（全局停靠条 + 聊天框，经 `App.tsx` 挂在路由之外、所有页面可见）；`frontend/src/pages/ItemForm.tsx`（解析 URL query 预填）
- **后端**：`backend/app/api/v1/ai.py`（`chat` 接口 + `suggest-locations` 接口）；`backend/app/services/ai_service.py`（模型调用 + System Prompt + 规则降级兜底）；`backend/app/schemas/ai.py`（Pydantic 请求/响应模型）
- **数据流**：用户在悬浮窗输入 → `POST /api/v1/ai/chat`（携带 `page`、`action`）→ 模型提取返回 `form_patch` → 前端 `navigate('/publish?ai_prefill=<encoded json>')` → `ItemForm` 用 `useEffect` 解析 query 预填 → `replaceState` 清掉 query

## 4. API 接口文档

### POST /api/v1/ai/chat（需 Bearer token）

请求体：

| 字段 | 类型 | 说明 |
|---|---|---|
| `message` | string（必填，1-2000，去首尾空白） | 用户输入 |
| `page` | string（可选） | 当前页面标识，供回复上下文 |
| `action` | `"draft"`（可选） | 强制提取表单字段（不再仅闲聊） |

响应体：

| 字段 | 类型 | 说明 |
|---|---|---|
| `intent` | string | 意图（如 lost / found / chat） |
| `reply` | string | 给用户看的回复文本 |
| `form_patch` | object \| null | 提取的字段：`category`、`title`、`description`、`location_area`、`building_code`、`floor`、`time_occurred`；未提及的字段不返回（不填空串） |
| `actions` | list[string] | 建议动作（如 `navigate:/publish`） |
| `source` | `"model"` \| `"rule"` | 结果来源标识 |
| `degraded` | bool | 是否降级（模型不可用走规则） |

### GET /api/v1/ai/suggest-locations（需 Bearer token）

- 参数：`keyword`（可选，最长 64，按关键词过滤）
- 返回：`{"locations": ["图书馆", "第一食堂", ...]}` —— 历史发帖地点频次 top5

## 5. 核心实现要点

- **预填用 URL query 而非 sessionStorage**：`useState(() => readAiPrefill())` 初始化器带"读后即清"副作用，在 React.StrictMode 双渲染下第一次读清、第二次读到 null 导致预填丢失；改为 `/publish?ai_prefill=<encoded>` + `useEffect` 纯解析（StrictMode 安全），读后 `replaceState` 清 query
- **拖动用 `transform: translate()`**（GPU 加速），拖动中禁用 transition，松手恢复 `transition: transform 0.3s cubic-bezier(0.4,0,0.2,1)` 吸附动画
- **双侧吸附**：松手按悬浮条中心 x 与视口中线比较，吸附到较近一侧（默认左侧垂直居中）
- **预填只填空字段**：`direction` 仅表单空白时同步，用户手写/preset 绝不覆盖
- **System Prompt** 注入 `current_date`（避免模型把"今天"换算成训练截止日期）；`floor` 在 `_merge_draft` 后做正则兜底（`/\d+楼|层/`）
- **测试隔离**：conftest autouse 禁用模型，不依赖 .env 真实状态

## 6. 已知问题与注意事项

- 预填字段名必须和后端 `form_patch` 返回的 key 完全一致（`location_area`、`building_code` 等 snake_case）
- 模型不可用（超时/403/未配置）时自动降级规则模式，接口不报错，悬浮窗正常可用
- Console.log 标记 `[AiFloat]`/`[AiPrefill]` 仅开发调试用，上线前可移除
- 模型网关偶发 403 属临时限流，无需改 .env 配置
- `img01.png`、`campus-lost-found-main/` 等本地文件已在 .gitignore 排除，不会入库

## 7. 本地启动步骤

后端（首次需 `python seed.py` 初始化管理员与图层）：

```
cd backend
.venv\Scripts\activate
.venv\Scripts\python -m uvicorn app.main:app --reload --port 8000
```

前端：

```
cd frontend
npm install
npm run dev
```

模型验证（token 换取方式见下）：

```
curl -s -X POST http://127.0.0.1:8000/api/v1/ai/chat ^
  -H "Content-Type: application/json" ^
  -H "Authorization: Bearer <token>" ^
  -d "{\"message\":\"今天在图书馆3楼丢了蓝色折叠伞\"}"
```

预期：`source: "model"`、`degraded: false`、`form_patch.floor: 3`、`time_occurred` 为当天日期。

token 获取：

```
curl -s -X POST http://127.0.0.1:8000/api/v1/auth/login ^
  -H "Content-Type: application/json" ^
  -d "{\"username\":\"<账号>\",\"password\":\"<密码>\"}"
```
