# 会话摘要：05-地图状态栏拖拽归位修复

- 日期时间：2026-10-22 18:08:28
- 分支：feature/ai-model

## 任务目标

修复地图页底部状态栏（抽屉）唤起后拖拽不能有效归位的 BUG：
拖拽松手后跳回原处、卡住不动、或无法归位。只改状态栏拖拽归位，不重构地图主逻辑。

## 根因

1. click 与拖拽冲突（主根因）：把手同时绑定 pointer 拖拽切换与 onClick 切换，
   拖拽超过 40px 阈值触发 setExpanded 后，松手时 click 再次 toggle，展开被立即收起（"跳回原处"）。
2. ±40px 死区且拖拽不跟手：拖拽中高度不变，累计位移来回抵消时永远不触发（"卡住不动"）。
3. 缺 onPointerCancel 处理：拖拽被打断时状态残留。
4. pointerup 未显式 releasePointerCapture。
5. 拖拽中无 user-select:none。
6. 无边界 clamp、无中间档位，越阈值后两态突跳（"飞"）。

## 改动文件与行号

### frontend/src/pages/MapView.tsx

- 41-58：新增 DrawerState（collapsed/half/expanded）、DrawerAnchors 类型，
  drawerAnchors()（收起 190/220px、半开 40/45vh、展开 68/72vh）与
  nearestDrawerState()（吸附最近锚点）。
- 113-121：expanded 布尔状态替换为 drawerState 三态 + dragHeight 拖拽中实时高度；
  dragRef 扩展为 { startY, startHeight, height, anchors }；新增 drawerRef、dragMovedRef。
- 162-172：新增 dragging 派生值与 useEffect——拖拽中给 document.body 加 user-select:none，结束时恢复。
- 221-231：新增 finishDrawerDrag()——清 dragRef、显式 releasePointerCapture、
  清内联高度并按最近锚点吸附归位；pointerup 与 pointercancel 共用。
- 348-397：drawer section 加 ref、dragging class 与内联高度；
  handle 重写：pointerdown 记录 getBoundingClientRect().height 接力（不用 offsetLeft）；
  pointermove 实时跟手并 clamp 到 [collapsed, expanded]；位移 ≥4px 才算拖拽，
  click 检测到真实拖拽则不 toggle（消除根因 1）；键盘 Enter/Space 保留。
- 405-409：tabs 点击 setExpanded(true) 改为 setDrawerState('expanded')。

### frontend/src/pages/MapView.module.css

- 106-116：新增 .drawerHalf（40vh）、.drawerDragging（transition:none + user-select:none）。
- 118-120：.drawerDragging .handle 拖拽中 cursor:grabbing。
- 133：桌面媒体查询内补 .drawerHalf（45vh）。
