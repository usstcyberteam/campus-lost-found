# 会话摘要：System Prompt 优化（失物招领场景适配）

## 基本信息

- 日期时间：2026-10-22 深夜
- 分支：feature/ai-model
- 任务目标：优化 chat 接口的 System Prompt，提升校园失物招领场景表现——模糊描述引导补充而非强行预填；完整描述确认并预填；form_patch 只含明确提到的信息；保留降级机制

## 修改文件与内容

### backend/app/services/ai_service.py（2 处核心改动）

1. **`_CHAT_SYSTEM_PROMPT` 重写**（约 51-77 行）：
   - 身份强化：校园失物招领智能助手，专注校园场景（图书馆、食堂、教学楼、宿舍、操场）
   - 对话策略：语气亲切简短（≤60 字）；物品名 + 颜色样式/时间/建筑楼层至少一项 → intent="draft" 直接确认预填；只有物品名（如"掉了一把伞"）→ intent="chat" 引导补充、form_patch 必须 null；普通咨询 → "chat"
   - form_patch 硬规则：只填明确提到的信息、未提及一律 null（禁止空字符串、禁止推断编造）；category 限定常见类别枚举；title ≤30 字；location_area 只到建筑楼层级；building_code 给了编码示例（图书馆 B02）
   - JSON 锁死四字段 + 禁 markdown + 隐私红线（禁座位/柜号级位置、联系方式、认领证据）
2. **chat 提取逻辑修正**：
   - 新增 `_chat_form_patch(db, text, payload)`：直接取模型给出的值，**不再用 `_merge_draft` 规则底座强制填充**（旧行为：模型 form_patch 为空也会被规则全填，导致模糊描述被强行预填）；例外：floor 允许原文正则兜底（"3楼"属于用户明确提到的信息）；全字段空 → 返回 None 不预填
   - `_chat_messages`：system prompt 动态追加当前时间（`当前时间：2026-10-22 23:05`），供模型换算"今天/昨天"相对时间，修复幻觉日期
   - `_model_chat(db, text, payload)` 签名相应调整

### backend/tests/test_ai_chat.py（新增 2 用例 + 清理）

- `test_chat_vague_description_guides_instead_of_prefill`：模糊描述 → chat + 引导、form_patch null、actions 空
- `test_chat_form_patch_skips_unmentioned_fields`：模型只给 category/title → 其余字段 null（不被规则填充）
- 清理未使用的 `model_client` 导入（ruff F401）

## 降级分支位置（未改动，机制保留）

`chat()` 中模型不可用/超时/输出无法解析 → `_rule_chat()`（规则路径）：物品特征命中 → 规则 form_patch；无特征 → 引导话术。接口始终 200。

## 验证结果（真实模型 DeepSeek-V4-Flash 实测）

| 场景 | 结果 |
|---|---|
| "刚才掉了一把伞" | intent=chat，回复"别着急，能说说伞的颜色样式、大概什么时间、在哪个建筑和楼层丢的吗？"，form_patch=null，actions=[] ✅ |
| "今天下午3点在图书馆3楼丢了一把蓝色折叠伞" | intent=draft，回复确认语，form_patch：雨伞/标题/B02/图书馆3F/floor=3/time_occurred=2026-10-22T15:00:00，actions=["prefill_form"] ✅ |
| JSON 结构 | 六字段锁死无增删 ✅（前端 applyPatch 只填空字段 + toast 逻辑未动，正常触发） |

### 实测发现并修复的两个模型问题

1. floor 漏提取 → 原文正则兜底（"3楼"→3）
2. 幻觉日期（"今天"被换算成 2025-06-13）→ system prompt 注入当前时间后正确换算为 2026-10-22
