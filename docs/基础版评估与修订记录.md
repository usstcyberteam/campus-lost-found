# 基础版评估与修订记录

日期：2026-10-04。修订工具：Codex。原有开发来源以真实记录为准，本文件不生成或替代码道使用证明。

## 评估结论

初始版本可以构建，基础鉴权、物品记录和业务接口已有实现；但工作人员无法从网页完成认领核验，且认领归属、多申请状态与幂等存在缺陷。本轮完善后形成可在网页完成的基础归还流程，仍不等于完整参赛产品。

## 实际修订

| 范围 | 原问题 | 处理 |
|---|---|---|
| 归属 | 可关联他人寻物并将其关闭 | 创建、核验及归还检查归属与状态 |
| 幂等 | 跨账号复用键返回原申请 | 限定账号与相同请求内容，冲突返回 409 |
| 多申请 | 拒绝竞争申请阻断已通过申请归还 | 查询有效申请后恢复状态；每件拾获物最多一个核验通过 |
| 归还 | 剩余申请状态悬空 | 事务内完成归还并拒绝竞争申请，恢复其尚未匹配的寻物状态 |
| 工作人员 | 缺少申请与证据查看入口 | 新增受限列表、详情接口及审核归还页 |
| 输入 | 长密码返回 500、空字段可发布 | UTF-8 字节校验、字段长度及空白校验；错误不回显密码 |
| 候选 | GET 反复写入重复记录 | 只读规则排序，最多三个候选 |
| 模型来源 | 未调用模型却标记 model | 未实现适配器始终明确为手动降级 |
| 前端 | 手填记录 UUID、提交后状态滞后 | 本人记录选择框、候选链接、提交状态更新与稳定幂等键 |
| 会话 | 刷新后丢失登录 | sessionStorage 保存令牌并经 /auth/me 重新校验 |
| 工单 | 接单竞争、任意处理人员按钮、原生 prompt 兼容问题 | 条件更新、本人按钮、页面内反馈表单与取消按钮 |
| 地图 | 实例、请求、对象 URL 未充分清理 | 切换和卸载时清理；底图失败明确提示 |
| 部署 | Docker 代理使用容器 localhost、固定签名密钥与默认密码 | 环境配置与服务名代理、构建忽略规则和本地配置生成 |

## 实际验证记录

- 原版：后端 6 个测试通过，前端 Vite 5 构建通过。
- 修订后第一轮：18 项通过、1 项 PostgreSQL 并发用例跳过。既有 Starlette/httpx 测试适配弃用警告仍存在，不影响本轮通过结果。
- 前端：Vite 7.3.6 构建通过。依赖审计原有 4 项问题，更新相关依赖后报告 0 项已知漏洞。依据包含 [Vite 官方安全公告](https://github.com/vitejs/vite/security/advisories/GHSA-fx2h-pf6j-xcff)。
- Compose：`docker compose config --quiet` 通过；Docker 引擎仍无法连接，未宣称容器或 PostgreSQL 并发通过。
- 浏览器：在独立端口 8001/5174、独立 `browser_test.db` 中，用演示账号实际完成学生发布、规则候选、空证据提示、认领、工作人员证据查看、核验、归还及学生最终状态查看。
- 登录刷新、地图切换与离开、工单取消不保存及确认反馈均实际检查。浏览器发现原生 `prompt` 不支持，已改为页面内编辑并重新验证取消、提交两条路径。
- 浏览器截图保存于本地 `.artifacts/`，不上传演示账户数据库或截图中的私密证据。

最终回归与构建结果以交付时实际输出为准；本记录中的阶段验证不替代全新环境复现。
